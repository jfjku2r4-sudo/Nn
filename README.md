# الأستاذ الذكي — مساعد الثانوية العامة

تطبيق تعليمي عربي مبني باستخدام Streamlit و Gemini API.

## المزايا
- واجهة عربية RTL بأزرار حقيقية.
- رفع ملفات PDF والصور والنصوص.
- شرح الدروس حسب الصفحة والجزء.
- اختبارات شاملة ومخصصة بثلاثة مستويات.
- اختبارات متدرجة: سهل ثم متوسط ثم صعب.
- تحديد عدد الأسئلة وفرص التلميحات.
- تلميح واحد لكل سؤال مع رصيد محدود لكل اختبار.
- البحث عن المعلومات والقوانين باستخدام Google Search grounding عند تفعيله.
- إنشاء إنفوجرافيك باستخدام نموذج Gemini يدعم توليد الصور.

## التشغيل محليًا

1. ثبّت Python 3.10 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. أنشئ بيئة افتراضية (اختياري):
   `python -m venv .venv`
4. فعّل البيئة الافتراضية.
5. ثبّت المكتبات:
   `pip install -r requirements.txt`
6. انسخ `.env.example` إلى `.env` وضع مفتاح Gemini API.
7. شغّل:
   `streamlit run app.py`

يمكنك أيضًا إدخال مفتاح API من الشريط الجانبي داخل التطبيق.

## النشر على Streamlit Community Cloud

1. ارفع ملفات المشروع إلى مستودع GitHub خاص أو عام.
2. أنشئ تطبيقًا جديدًا في Streamlit Community Cloud.
3. اختر `app.py` كملف التشغيل.
4. من إعدادات التطبيق أضف Secret:
   `GEMINI_API_KEY = "مفتاحك"`
5. انشر التطبيق.

## تنبيهات مهمة
- لا ترفع مفتاح API إلى GitHub ولا تشاركه مع أي شخص.
- المفتاح الذي تدخله في الشريط الجانبي يبقى في جلسة التطبيق الحالية، لكن الأفضل استخدام Secrets عند النشر.
- توليد الصور يعتمد على توفر نموذج يدعم إخراج الصور في حساب Gemini API؛ إذا لم يكن النموذج الافتراضي متاحًا، غيّر `GEMINI_IMAGE_MODEL` إلى اسم نموذج الصور المتاح لك.
- ملفات PDF والصور تُرسل إلى Gemini مع الطلبات التي تحتاج تحليلها؛ لا ترفع ملفات شخصية أو حساسة.
- رصيد التلميحات محفوظ في جلسة Streamlit الحالية، وليس قاعدة بيانات دائمة. إعادة تشغيل الجلسة قد تفقد تقدم الاختبار.
- هذا إصدار أولي قابل للتطوير، ويحتاج اختبارًا على ملفات ومناهج فعلية قبل الاعتماد عليه في امتحان رسمي.
